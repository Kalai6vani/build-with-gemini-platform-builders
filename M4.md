# Step 1 · Check observability status across all agents
M4 · Observe the Trajectory — Instructions

M1 settled who each agent is and what data it may touch. M2 controlled connections and tools. M3 screened incoming content. M4 gives you full visibility into what happens inside the execution loop.

# Key objective
Activate OpenTelemetry Distributed Tracing and Full Prompt/Response Output Logging across deployed Reasoning Engines to capture multi-agent trajectories and tool executions.

- See the Telemetry Gap: Audit all deployed agents and discover that auto-instrumentation and message content capture are missing on the Markdown Strategy Agent.
- Activate Auto-Instrumentation: Configure OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT="SPAN_AND_EVENT" on the Markdown Strategy Agent runtime.
- Trace a Multi-Agent Escalation: Send a live price-match request for the TerraMow Robotic Lawn Mower (SKU: SKU-HSE-4002) and inspect the complete distributed trace from Price Match Agent → Markdown Strategy Agent → BigQuery MCP tool calls.
- Verify Behavioral Governance: Inspect Cloud Trace spans and payload logs to prove every reasoning step, prompt, and tool response is auditable.
Why it matters: You cannot govern what you cannot see. Traditional metrics (CPU and network uptime) only tell you an agent is running. Distributed tracing captures why an agent made a decision, how it traversed its reasoning tree, and exactly what data flowed between agents.

# Where we left off
Every agent has its own identity (M1), connection perimeters and database tools are fail-closed (M2), and incoming prompts are screened for jailbreaks (M3). What you still lack is deep observability into multi-agent execution paths.

Find out which agents have telemetry and payload logging enabled, and which are operating blind. Ask agy:

**Antigravity**
```text
Is observability, input and output logging enabled for all the agents?
```

What to expect: agy audits the deployment specifications across all deployed agents. It reports that while the Price Match Agent and Customer Personalization Agent have OpenTelemetry logging active, the Markdown Strategy Agent has message content capture disabled or unconfigured.

# Step 3 · Trace an end-to-end multi-agent escalation
Execute a live price match requiring back-office escalation and inspect the full distributed trace across agent boundaries. Ask agy:

**Antigravity**
```text
Can we price match the TerraMow Robotic Lawn Mower (SKU: SKU-HSE-4002) against competitor BetaBuy? Our shelf price is $1499.00, and BetaBuy is advertising it for $1274.15 (a 15% discount). Can you approve this price match? Show me the trace details and input output response logging captured.
```

What to expect: agy invokes the Price Match Agent, which verifies the competitor listing and escalates to the Markdown Strategy Agent. The Markdown Strategy Agent executes BigQuery MCP tool calls, validates margins, and approves the override. agy extracts and presents the complete OpenTelemetry trace hierarchy showing root spans, child A2A spans, and tool execution payloads.
