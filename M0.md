# Step 1 · Check your environment
# M0 · See Everything — Instructions

In this mission you find out what your AI estate actually looks like — what NovaSmart says it runs, what is really running, and who has been reading customer data.

This tab is what you do — the prompt to type and a one-line check that it worked. The story, the background and the sample results live on the Reference Guide tab.

# Key objective
See your AI estate as it really is: what Google Cloud Agent Registry has on record, and what is actually running on Cloud Run and the managed agent runtime.

- Read the official Agent Registry catalog of the agents NovaSmart says it has.
- List what is actually running, and compare that list against the catalog.
- Read the Cloud Audit Logs trail of who has been reading the customer database.
- Decide what should happen next. This mission changes nothing; M1 is where fixing starts.
Why it matters: you cannot govern what you cannot see, and an agent running outside central oversight cannot be audited or verified.
